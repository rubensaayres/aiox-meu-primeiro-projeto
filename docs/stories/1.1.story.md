# Story 1.1 — Criar Página de Boas-Vindas

**Status:** Done
**Story ID:** STORY-1.1
**Epic:** Epic 1 - Core Experience
**Priority:** High
**Complexity:** Small (2 points)

## 🎯 Description
**User Story:** Como um usuário do sistema, desejo ver uma página de boas-vindas personalizada ao acessar a aplicação, para que eu me sinta acolhido e saiba que estou no ambiente correto.

**Pain Point:** O usuário atualmente não possui uma página inicial, resultando em uma experiência de entrada fria e desorientadora.

## ✅ Acceptance Criteria
- [ ] **AC1: Mensagem de Boas-Vindas**
    - **Given:** O usuário acessou a URL raiz da aplicação.
    - **When:** A página é carregada.
    - **Then:** Deve ser exibida uma mensagem clara de boas-vindas (ex: "Bem-vindo ao Sistema AIOX!").
- [ ] **AC2: Personalização de Nome**
    - **Given:** O usuário está autenticado.
    - **When:** A página de boas-vindas é renderizada.
    - **Then:** O nome do usuário deve ser exibido dinamicamente na saudação (ex: "Olá, [Nome do Usuário]!").
- [ ] **AC3: Responsividade Total**
    - **Given:** A página é aberta em diferentes dispositivos.
    - **When:** O viewport é alterado (Mobile < 768px, Tablet 768px-1024px, Desktop > 1024px).
    - **Then:** O layout deve se ajustar automaticamente, mantendo a legibilidade e o alinhamento dos elementos.

## 📦 Scope
**IN:**
- Criação do componente de página de boas-vindas.
- Implementação da lógica de saudação personalizada.
- Estilização CSS responsiva.
- Testes de UI em múltiplos viewports.

**OUT:**
- Implementação de sistema de autenticação completo (estamos assumindo que o nome do usuário vem de um contexto já existente).
- Outras páginas do sistema.
